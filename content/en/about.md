I'm Lei Xia, a backend architect. I've been writing on this blog since 2014.

I started with PHP, Node.js, Go and frontend work, moved on to microservices and distributed systems, and now focus on **AI agent engineering**: making agents reliable, observable and testable in production.

This blog covers engineering problems I've actually run into — the trade-offs, and code that works.
